How it works

  • Read and correct. Literal blocks, run styles and directions, list starts, table cells, image size and reading order have bounded editing controls. The original stays separately available.
  • Review the actual file. Build PDF creates saved bytes and a selected-page preview. Download and Use are separate deliberate actions. Unsupported PDF text stays editable rather than losing characters.
  • Finite local processing. Files are processed in this tab. DOCX is limited to 32 MiB, Markdown to 8 MiB source, logical text to one million units, and retained images to 48 IDs / 16 MiB. Existing task and temporary work share the session limits.

Frequently asked questions

Which Markdown is supported?

The supported subset includes headings, emphasis, code, numbered and bullet lists, pipe tables and owned local image references. Apply source shows the parsed model. It is not a general CommonMark claim.

When does a download start?

Only when you press Download result after preparing and reviewing a saved file. Building, importing and retrying never start a download.

Can I export Arabic or Hebrew as PDF?

The exact text remains editable. RTL and other unproved script or positioning cases show a precise unsupported PDF state before font loading; there is no silent character substitution.
