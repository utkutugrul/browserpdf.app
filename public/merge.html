    How it works

    • Add files in any order, then use the up/down arrows to arrange the order they'll appear in the final PDF.
    • Merging happens locally using pdf-lib in this browser tab. BrowserPDF has no file-upload endpoint.
    • Page counts shown per file are read directly from each PDF so you know what you're combining before you merge.

    Frequently asked questions

    Is there a limit on how many PDFs I can merge?

    No fixed limit. Files are combined in your browser's memory, so the practical ceiling is your device, not a quota on our side.

    Can I change the file order before merging?

    Yes. Drag rows into position, or use the arrow buttons; the merged PDF follows the order shown in the list.

    Does merging reduce quality?

    No. Pages are copied into the new document losslessly; nothing is re-rendered or recompressed.
