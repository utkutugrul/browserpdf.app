How it works

  • Rendered locally by pdf.js the open-source PDF engine from Mozilla draws each page directly onto a canvas in this tab. Your file is never sent to a server.
  • Zoom and navigate step through pages with the buttons or the arrow keys, zoom in and out, fit to the width of the window, and print when you're done.
  • Nothing is uploaded. Reading, zooming, and printing all happen entirely in this browser tab, there's no server involved at all for this tool.

Frequently asked questions

Can I print the PDF from the viewer?

Yes. The Print button opens the original PDF in a new browser tab and hands it to your browser's built-in print dialog. No re-rendering, no quality loss.

Does the viewer work offline after loading?

Once pdf.js and this page have loaded, the PDF you open is rendered entirely on your device. Opening a new file needs no network call, though the page itself must already be loaded.

Is there a file size limit?

There is no server-side limit because nothing is uploaded. The only constraint is your device's available memory; very large PDFs may render slowly but will still open.
