Operation

Each edited field supports 4096 UTF-16 units. Commas and whitespace are text, not keyword separators. Creation date is preserved; editing updates modification date.

Standard cleanup removes Title, Author, Subject, Keywords, Creator, Producer, CreationDate and ModDate from Info only. XMP, attachments, forms, links and other hidden content are outside cleanup scope. A rewrite can invalidate a digital signature.

How it works

  • Only fields you change are rewritten. A blank edited value is stored as blank; the cleanup operation removes the eight standard entries.
  • The saved copy is reopened and its standard fields are checked. Download is explicit. Use chooses this copy for Privacy Scan, Document Doctor or Reader.
  • This is standard Info editing, not comprehensive privacy cleanup. XMP and other content can still identify a document.

Frequently asked questions

Which fields can I edit?

Title, author, subject, keywords, creator and producer. Dates are shown in the comparison. Oversized or unrepresentable stored text remains unchanged until you explicitly replace it.

Will every reader show the same properties?

Reader displays vary. This tool checks the saved standard Info values; separate XMP metadata can contain different values.

Does cleanup remove all private information?

No. It removes only eight standard Info entries. Review the chosen copy in Privacy Scan for other detectable categories and the scan's coverage limits.
