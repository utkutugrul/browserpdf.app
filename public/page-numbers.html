How it works

  • Numbers are drawn into the PDF itself with pdf-lib (11pt Helvetica, subtle gray), so they print and display everywhere.
  • "Page 1 of N" counts what it numbers: if you skip a cover page, the total reflects the numbered pages, and counting can start at any value.
  • Nothing is uploaded. Everything happens in this browser tab.

Frequently asked questions

Can numbering skip the cover page?

Yes. Enable "skip the first page" and numbering starts on page two, with the "Page X of N" total counting only the numbered pages.

Which positions can the numbers go in?

Six positions: top or bottom, each in the left corner, center, or right corner.

Can I start counting from a number other than 1?

Yes. Set any starting value, useful when the document continues from another file.
