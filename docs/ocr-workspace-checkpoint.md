# OCR pure model and searchable PDF writer checkpoint

This checkpoint adds five pure paths: `public/js/core/ocr-model.js`, `public/js/core/ocr-writer.js`, their two Node unit suites, and this document. It does not connect the existing OCR route, distribute Tesseract, load models/fonts, render previews, download, adopt a result, or change shared session/handoff APIs. Those integrations remain a separate reviewed phase. The writer accepts a source PDF; optional image intake must first produce an explicitly owned source PDF in a later reviewed adapter.

## Literal model and draft

`validateOcrModel(input)` returns a canonical fresh own-data model. Its exact fields are `version:1`, `source:{sha256,byteLength,pageCount}`, zero-based `selection`, and `pages`. A page carries `pageIndex`, source-content status (`unprocessed`, `recognized`, `blank`, `embedded`, `manual`), confidence, independent raw page text, captured geometry, lines, and a separate last-attempt status/error. A failed or cancelled attempt changes no preceding recognized text. A successful page replacement is atomic.

Geometry contains the actual source PDF.js `view`, rotation and UserUnit, recognition rotation/scale, actual viewport dimensions/affine transform, backing dimensions and the inverse public render output-scale matrix `toViewport`. The writer obtains the actual public viewport again and calls `convertToPdfPoint` after applying that inverse matrix. Positive axis output scaling is supported. It never guesses a CropBox offset, divides out UserUnit separately, or changes source rotation. The first-party renderer must supply its actual capture; this module does not attest that an OCR image was rendered from a particular snapshot.

A line has a stable unique ID, literal editable `text`, confidence, explicit OCR/manual source, editable bbox, original `rawBbox`, original baseline/row attributes, inclusion and review flags. OCR provenance is immutable under draft edits: `rawText`, `content`, `separator`, `projection:'single-terminal-lf-v1'`. Exactly one final U+000A is separated on recognition admission. Require the canonical split and `rawText === content + separator`. Page raw text is never reconstructed from these lines. User-edited text is never automatically stripped. Manual lines have null OCR provenance/original box, not invented recognition metadata.

An internal or repeated LF, CR/CRLF residual, TAB, C0/C1, U+2028/U+2029, unproved direction/format/combining positioning, or unavailable glyph stays visible and unsupported until deliberate correction or exclusion. Included unsupported text blocks writing. Empty lines remain explicit in model/coverage/history and emit no glyph. All-empty output raises `OCR_WRITER_EMPTY`. Spaces remain literal saved glyphs; a spaces-only overlay does not claim added searchable terms. There is no normalization, character filtering or hidden fallback.

`createOcrDraft(model,{owner,sessionUsage,getExternalUsage})` provides `snapshot`, `view`, bounded `rows`, async `apply`, `undo`, `redo`, explicit `clearUndo`, canonical `acceptOwner`, `drained`, and idempotent async `dispose`. Owner is `{taskId,revision,generation}`. Commands are `select-pages`, `replace-page`, `record-attempt`, `add-line` (manual only), `set-text`, `set-box`, `include-line`, and `review-line`; exact fields are checked per command. `apply(command,{signal,expectedRevision})` validates before publication, yields, then rechecks genuine signal, owner and draft revision. Failed admission does not auto-evict history. Before constructing a candidate, `apply` publishes a32MiB/two-representation pending reservation and registers its first promise before accounting callbacks. Once serialized, public usage includes the actual two candidate representations/count once. Commit transfers that charge to the committed entry without double-counting; failure releases it only after first settlement. `view` exposes pending bytes/count/phase and remains available with `closing:true` while disposal drains. Disposal drains the first pending mutation before clearing owned serialization bytes. Immutable JavaScript strings are not claimed physically erased.

Coverage exposes selected/recognized/unprocessed/embedded/blank/manual/pending/failed/cancelled pages, included/omitted/unreviewed/unsupported/empty lines and included pages. Changing the draft increments its revision, including undo/redo and attempt changes. Snapshots are copies; row DTOs contain at most40 lines and16384 string units including displayed provenance, IDs and policy fields.

## Writer entry and ownership

`preflightOcrWriter(model,{fontkit,fontBytes},{signal})` returns `needs-fonts` with the exact regular font request, `unsupported` with bounded line issues, `empty-no-glyphs`, or `ready` with actual public font metrics. It performs no reflow. Direct callers must reserve its bounded model/font/metrics work in the same first-party workspace accounting. `createOcrWriter(dependencies)` supplies `write`, `inspect`, `drained`, and idempotent async `dispose`; the writer entry performs joint reservations itself.

Dependencies are trusted injected pinned pdf-lib1.17.1, PDF.js6.2.108, fontkit1.1.1, the requested exact Noto font bytes, and trusted PDF.js asset options. Noto Sans Regular is569208 bytes, SHA256 `b85c38ecea8a7cfb39c24e395a4007474fa5a4fc864f6ee33309eb4948d232d5`. Existing font provenance/OFL and fontkit license files remain the source of notices. Fontkit UMD SHA256 is `d8df561b9fba98e24f2e5130e40948809281bbbc55a20c412359f1a0a5eb35a6`. Trusted module delivery stays with the later existing verified loader integration.

Call `writer.write(sourceBytes, snapshot.model, {signal, draftRevision:snapshot.revision, isCurrent, sessionUsage, getExternalUsage})`. `isCurrent` is required and must compare the captured source owner AND draft revision; it must not conflate job completion with later result-selection lifetime. `sessionUsage` returns the actual shared usage snapshot, including canonical owner fields. External usage must include concurrently retained draft/history/result resources; there is no disconnected OCR allowance. A successful result owns `bytes`, type, captured `draftRevision`, coverage, placements, known capabilities, usage, report and an idempotent byte disposer. Disposing the writer leaves already transferred result ownership with its caller. The result never adopts itself.

The writer hashes an owned source copy, checks source length/page count, verifies actual captured viewports, and uses the source document directly. It embeds a subset with `kern`, `liga`, `clig` disabled, requires one matching Unicode scalar per nonmissing glyph, global glyph-ID mapping consistency and zero positioning offsets. LTR Latin/Greek/Cyrillic/Common is the finite supported policy; this is not a claim that every character in those scripts is available. Bbox dimensions determine the hidden text scale. It appends invisible operators within a saved graphics state; original images/pages are not raster replacements. Embedded-text page replacement is unsupported, and existing text-layer removal is explicitly false. Runtime saved checks reopen actual page views/rotation/UserUnit. Independent owned tests verify literal saved ToUnicode glyph sequences, source pixels, streams, boxes, forms and URI links.

One active write is admitted. Genuine AbortSignal getters/listeners and global timer receiver are captured. Public PDF.js loading/destroy promises are owned, with one actual destroy invocation. Native pdf-lib save/embed promises are not abortable: cancel/dispose awaits their first settlement. Save bytes are captured before post-await cancellation checks, then cleared on rejection. Listener cleanup and all actual destroy attempts are independent. Failed cleanup keeps resources reserved and the lane fenced; `inspect` never advertises release or physical exit acknowledgement. A writer or draft setup failure does not strand an active lease. A separate failure-present flag handles even false/0/empty-string/null/undefined native rejections as failures after drain. Unknown native failures have a finite public error with retained nonenumerable cause; original genuine abort reasons retain identity.

Successful A remains owned separately and may only be explicitly reselected with its frozen revision/coverage and selected preview before manual Download/Use/handoff/history. Partial, unsupported, dirty or failed current candidates never silently substitute A. Preserve known source capabilities when combining the writer's positive facts; a spaces-only result omits a new searchability claim. No shared draft/session/result signature has been fabricated or changed here.
