# Spreadsheet reader and intake checkpoint

First pure reader/admission checkpoint for PDF to Excel and Excel to PDF. Five new files only. Existing routes do not import them. No UI, writer, formula engine, loader, OCR recognition or session transfer is added; services remain incomplete.

## Public APIs

`readSpreadsheetDocument(input, options, environment = {})` in `core/spreadsheet-document.js` accepts fixed, nonshared intrinsic Uint8Array or ArrayBuffer bytes. It captures their real backing, offset and length, reserves before copying, then owns an independent source baseline. Instance slice/species/iterators and spoofed signals are not used. Resizable or shared backing is rejected. The raw input maximum is 8 MiB.

Options are own plain data: required `kind: 'xlsx' | 'csv'`, `name` up to 260 units, `getUsage()`; CSV also requires an explicit `delimiter` from comma, tab, semicolon or pipe. Optional `signal` must be a genuine AbortSignal; `isCurrent()` and `onUsage(usage)` are trusted callbacks. Environment optionally contains the trusted `formatValue(format, value, {date1904})` public formatter adapter. There is no SDK acquisition here. Genuine caller aborts propagate the exact reason, including false, zero and empty string. ZIP receives a private genuine signal; XML receives a trusted guard.

`getUsage()` returns `{snapshot, live}` with actual canonical retained/resource/count fields and every external allocation, including old A and pending native reads. Its live total MUST exclude this reader's own currently reported lease. `onUsage` synchronously replaces that one lease, never adds a second copy. Each replacement is prospectively checked through the accepted shared budget helper. The last usage/budget callback precedes the final current predicate and intrinsic signal/closing guard; no callback follows that gate. A callback may cancel or change the owner before a result escapes. The caller owns owner-generation comparison, and must include its actual canonical tuple in this integration.

The first promise returns a frozen owned object:

- `model` and `modelBytes`: validated frozen accepted spreadsheet model and its owned serialized bytes, or BOTH null for a blocking source choice.
- `sourceBytes`: independent original file bytes, preserved through model edits and never rewritten as normalized output.
- `provenance`: frozen finite source sidecar, and `provenanceBytes`: owned JSON bytes for `{provenance, report}`.
- `report`: frozen bounded rows with `code`, `message`, `part`, `cell`, `severity: 'choice' | 'information'`.
- `status`: `review-ready`, `needs-choice` or `empty`. These concern the reader projection only and authorize no publication or export.
- `usage`: actual resident `resourceBytes`, `resourceCount` plus this reader's `workVisits` and `actions`.
- `dispose()`: idempotent FIRST promise. It captures actual owned buffers and the validated bundle, erases buffers and releases its lease within FIRST cleanup. Failed release dominates parse/cancel, caching typed CLEANUP with exact cause/owned refs/last conservative reservation; no retry. Model/sidecar strings are immutable values, not physically zeroizable; consumers must drop references. Owned byte views are trusted-consumer read-only data. They must not be mutated, transferred, detached or retained past disposal.

`needs-choice` retains bounded original source and diagnostics with `model: null`; it never returns a usable partial model. If even the finite diagnostics/source representation cannot fit, the promise rejects. No silent eviction/truncation or automatic recovery is performed. Typed reader errors have `SPREADSHEET_DOCUMENT_*` codes. Encoding/CSV diagnostics use source byte intervals. UTF8 failure intervals include up to three carry bytes and identify the bounded failing decoder chunk, not a fabricated exact malformed-byte location.

`createSpreadsheetIntake({getOwner, getUsage, readCandidate, publishCandidate, onState?})` in `spreadsheet-intake.js` is a DOM-free File lane. `getOwner()` returns actual own `{taskId, revision, generation}`; `getUsage()` returns actual canonical/external usage excluding intake reservations. Full snapshots (up to 64 own data keys) keep identity/metadata; required own scalars are validated, never getters. It exposes `select(actualFile, {intent, signal?, isCurrent?, delimiter?})`, `cancel(reason?)`, `drain()`, `dispose()`, `snapshot()`. Select accepts XLSX/CSV/TSV extensions and compatible MIME types, rejects legacy XLS, and requires a delimiter for CSV/TSV. Native name/type/size/read methods are captured intrinsically, bypassing instance overrides.

`readCandidate(bytes, frozenDescriptor, context)` must call `context.onUsage()` BEFORE constructing reader-owned resources. Use the core reader with `context.getUsage`, `context.onUsage`, `context.isCurrent` and `context.signal`. Candidate must advertise its own matching usage and own disposer. Context also exposes `owner`, `descriptor`, `reserve`, `reservationUsage`, `assertCurrent`. `reserve(extra).release()` is for trusted prospective integration leases; release only after the actual FIRST work/cleanup it covers settles.

`publishCandidate(candidate, context)` is a trusted integration callback returning `{owner}`. It MUST own actual canonical copy/transfer and result/Use/download/rail reservations, validate the actual candidate/status, and call `context.assertCurrent()` after its last callback and immediately before its own atomic publication. Intake does not implement or roll back external session transfer. The returned owner must equal the last actual canonical owner snapshot; no observer callback follows that final signal/closing check. Successful publication transfers candidate disposal responsibility to the publisher. Failed candidates are cleaned before the lane settles. Reader acceptance alone is never a PDF/workbook/rail result.

Select resolves `{status:'accepted', owner}`, `{status:'cancelled', reason}`, or `{status:'rejected', error}`. There is one active FIRST lane promise installed before caller callbacks, plus only the latest unread File descriptor. A reentrant newer select wins. Replacement/cancel invalidates immediately; raw read, parser, formatter, publisher and disposer promises are awaited without race or duplicate reads. Zero-usage cleanup notices do not release leases before the FIRST parser/disposer settles. Failure retains A. Failed owned cleanup shares one cached error across select/drain/dispose, retains candidate/raw/reservations and exposes `cleanupBlocked` and its full `snapshot().usage`, and fences future selection/drain/disposal. There is no retry/early release. Dispose installs its FIRST marker before abort callbacks. State observers receive reading/parsing/committing and unsuccessful final phases; successful state comes from the select result. Observer failure cannot strand settlement.

## XLSX authority and finite representation

A declaration-only bounded EOCD/central-directory scan estimates expansion BEFORE calling the unchanged `admitOoxmlArchive`. It is not a second ZIP admission authority. Profile: raw 8 MiB, ALL-entry declared expansion 8 MiB, individual part 4 MiB, at most 64 entries and a 1 MiB directory. Only completed authoritative admission supplies parts to `readAdmittedXml`. ALL entries, including discarded/unsupported parts, receive the existing header/path/CRC/actual-expansion/XML checks. Images remain opaque retained package data; no PNG decoding/copy/rendering is added here. Existing image-header validation is inherited from admission.

Require typed local officeDocument to `xl/workbook.xml`, workbook relationship parts and correctly typed local worksheets/styles/sharedStrings. Key containers are checked. Duplicate names, identities, targets, rows/cells, missing/mismatched/external worksheet relationships, unsafe targets, unsupported namespace/Strict OOXML, binary/macros and legacy CFB fail. Dimensions never allocate or clip. Unsupported source features are reported and block a model; all original bytes remain. Default Calibri/style metadata and margins retain explicit projection information without forcing a choice. Relative column widths and editable print margins do not claim Excel pixel/print fidelity.

Model limits remain unchanged: 16 sheets, 10,000 aggregate rows, 100 columns, 200,000 rectangular slots including hidden/empty inventories; 32,767 units per cell, 1,024 per formula, 1,000 merges. Reader has 10,000 shared strings, 1,024 cell styles, 128 number formats of at most 256 units, 100 reports. Builder charge is capped at 8 MiB, provenance JSON at 2 MiB/known charge 4 MiB, and monotonic aggregate model/sidecar logical strings at one million UTF16 units. Conservative charging may reject below theoretical model maxima. No extra resource pool exists.

Preserve sheet order/names/visibility, row/column metadata, merged underlying values, defined print areas and original style/layout references. Source sidecar cells identify original part/address/type/numeric lexeme/style/format/formula attributes/cache provenance. Source sheetId/relationship IDs remain distinct from stable editable model IDs. Accepted model.source remains null for XLSX/CSV; no fake PDF page reference or model schema extension is invented.

Only explicitly typed XLSX scalar numbers/Booleans/errors/strings are decoded. Raw typed value, logical text/source lexeme, computed display, formula text and cache remain distinct. XML character rules and OOXML ST_Xstring escapes including escaped underscores and surrogate pairs are honored. Blank present cells differ from absent coordinates. Empty sheets retain a one-by-one extent with no stored cells. Formula text is never executed. Normal scalar source caches are labelled `source`; absent cache is `missing`, never invented zero. Shared/array/unsafe formula/cache, precision, unknown formats and unsupported features require a choice for the whole model. Accepted draft invalidates remaining imported caches on every edit; replacement of source requires a new review by the integrating owner.

No automatic JavaScript Date conversion. Numeric serial plus explicit date1904 remain original data. Format allowlist: General, 0, 0.00, #,##0, #,##0.00, 0%, 0.00%, yyyy-mm-dd and @. Formatter absence/failure/empty/oversized output blocks formatted numeric readiness without a raw fallback. Negative/out-of-range dates and the fictitious 1900 serial60 require a choice.

The exact already-adopted cached SheetJS0.18.5 asset was verified BEFORE private VM evaluation: 881727 bytes, SHA256 `c9506197caf809a075b6dee1da0d36fb19da7158ffe8a88e7b0c96c5d8623c99`, SHA384 `vtjasyidUo0kW94K5MXDXntzOJpQgBKXmE7e2Ga4LG0skTTLeBi97eFAXsqewJjw`. Sixteen public `XLSX.SSF.format` controls passed for every allowlisted format, 1900/1904, serial60 and percentages. Negative/out-of-range date output was empty; serial60 yielded fictitious1900-02-29. No read/write/private API, table mutation, download, new dependency or production SDK adoption occurred. Inject public SSF; `utils.format_cell` trusts/mutates `.w` and does not forward date1904.

## CSV

One sheet, fatal streaming UTF8 only, explicit delimiter. A single leading BOM is a recorded marker, later FEFF literal. Preserve field byte spans, quoted flag, empty fields, spacing, CR/LF/CRLF inside quotes and doubled quote escaping. Outside quotes CR/LF/CRLF terminate rows; after closing quote only delimiter/row-end/EOF is legal. Cross-chunk decoder/CRLF/scalar state is retained. No whole decoded copy, delimiter sniffing, formula/type/date inference or silent apostrophe insertion occurs.

Empty input has zero records/no cells. A blank row has a present empty string field; trailing delimiter adds a present empty field; final row terminator adds no phantom row. Short rows leave remaining coordinates absent. Values such as 001, =SUM(A1), +x, -42, @x and dates remain strings with formula:null. A future workbook writer must explicitly write string cells.

## Joint ledger and inherited limits

Every stage uses unchanged `assertDocumentWorkspaceBudget`: canonical retained artifacts plus ALL live artifacts/resources <=512 MiB; resources/expansion <=96 MiB and groups <=128. Old A/history, raw B, queued active native work and caller-owned copies remain charged. Native File read reserves 3N artifact bytes and one slot. Core input copy also exposes its own 3N artifact lease; this is intentionally conservative. Before authoritative ZIP work reserve `17 MiB + 2N + 4E` resource bytes and `54 + entryCount` groups. At the strict profile cap this is 65 MiB/118 groups plus actual canonical/native-read usage. CSV reserves 17 MiB+2N and four groups. Insufficient current headroom rejects a smaller file.

All parsing ends and the captured FIRST archive disposer settles before atomic stage replacement by actual builder+provenance+source charge. The accepted validator's fixed 48 MiB/two-resource stage is publicly visible for its entire FIRST promise, in addition to resident builder/source/sidecar and actual external usage. Only after validation returns does the lease become the owned validated model+sidecar+source total. Later createSpreadsheetDraft revalidates/copies; integration must retain this reader lease until that FIRST construction and reader disposal finish. No adoptBundle, history pruning, premature A credit or separate pool is used.

Own explicit work counts actual source copy bytes, scan/comparison/parse/format record actions and serialization traversal under 32 Mi visits; own loops yield at 16,384 visits or 128 actions. Shared XML retains its actual 64 KiB/256-event scheduler and 65,536-unit token bound. Native set/decoder/JSON/formatter calls are not preemptible. Shared XML callback parsing is synchronous and has its inherited scheduling, not an invented tighter async callback API. Formatting is one bounded input/output action at a time. No worker is introduced because the first chunk avoids XLSX.read and uses these accepted bounded stream/event APIs.

Native decompression/formatting may allocate before JS validates produced size. Existing ZIP uses allSettled for FIRST read/write/cancel/abort jobs and does not expose cleanup-success acknowledgement. The wrapper awaits that first admission job; it cannot invent successful physical cancellation or zeroization of private upstream early-failure buffers. Known overshoot stops before further copy/decode. Leases last through FIRST settlement; stronger upstream cleanup or hard native heap/RSS caps need separate shared-owner work. This is a logical prospective ledger, not an RSS guarantee or a count of every native object.
