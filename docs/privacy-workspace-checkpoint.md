## Pure behavior and ownership

The new DOM-free workspace core exports `PRIVACY_LIMITS`, `assertPrivacyWorkspaceBudget(snapshot,live={},extra={})`, `createPrivacyWorkQueue(run)`, `createPrivacyPdfLifetime()`, `createPrivacyPreview({canvas,ensurePdfJs,pdfjsAssets,lifetime})`, `privacyView(report,{page=1,offset=0}={})` and `privacyBoundary(priorBoundary,inputLosses=[],{rewrite=false,incomplete=false}={})`.

The budget accessor reads actual own metadata snapshot scalars, without calling `current`, `original` or `transfer` or importing the active Docs draft. Each usage descriptor has exactly the five optional finite nonnegative scalars `resourceBytes`, `resourceCount`, `artifactBytes`, `expandedBytes`, `expandedCount`. Joint resource bytes are canonical resourceBytes plus private resource/known expansion; joint resource count adds private resource/expansion entries; joint total is canonical retainedBytes plus every private artifact/resource/expanded byte. Limits are respectively 96 MiB, 128 and 512 MiB. Resource bytes already included in canonical retainedBytes are not added twice. There is no extra private pool. Near-boundary scalar tests are labelled synthetic arithmetic cases; the ordinary positive uses a real document-session snapshot and real PDF bytes.

The new queue exposes `submit(request)`, `cancel(reason)` and `drained()`. It owns one active first native work promise plus one latest unread descriptor. It aborts obsolete publication immediately, waits for the original work promise, and never reads an overwritten pending descriptor. A completed successful token remains current until another explicit intent or Cancel. The returned operation has the genuine signal, `isCurrent` and `assertCurrent`; Cancel preserves an explicit falsy reason. This queue has no automatic access to a route's unrelated native handles: the approved later controller must await the lifetime/shared-result barriers inside its work before starting a successor phase.

The PDF lifetime exposes `inspect(pdfjs,bytes,{signal,pdfjsAssets},callback)`, `cancel(reason)` and `drained({retry=false}={})`. This inspector has the actual legacy helper callback shape. It records first task/load/inspection/destruction promises, retains actual failed handles, fences another getDocument until explicit cleanup Retry succeeds, and does not treat a canceled promise as disposal. Task destruction initiated by abort is captured and drained. Returned documents are separately destroyed when that API exists; the pinned PDF.js document proxy does not require an invented destruction method. The loading task owns native teardown. Invalid or failed disposal stays fenced. Successful cleanup after a genuine cancellation preserves its exact reason, including null, false, zero and empty string. Failed disposal takes precedence and stays visible as `PRIVACY_CLEANUP`.

The injected selected-page preview has `open(bytes,{pageIndex=0,signal}={})`, `clear()` and `drained(options)`. It validates a nonempty Uint8Array of at most 32 MiB, 1..1000 actual pages, and finite zero-based selection, renders through the existing bounded helper at 900 pixels per edge/4 million pixels, waits for actual render and disposal, and only then writes its page marker. Clear revokes work and releases the browser canvas. Failed cleanup hides/clears the preview and keeps its handle for Retry. These new route opt-in limits do not change the accepted intake's 250,000,000-byte default.

The page view retains thirteen fixed category rows with observed count, explicit status/lower-bound, document/page scope and supported action identifiers. It emits at most 25 detail rows per view from bounded source locations. It never emits raw matches, URLs, scripts, attachment payloads or arbitrary field names. A page location is an integer page, not an invented geometric match rectangle. The boundary helper preserves the full prior loss union, adds actual scene/composition/rewrite/incomplete codes only from the accepted allowlist, and rejects a thirteenth loss before any publication instead of relying on shared slicing.
