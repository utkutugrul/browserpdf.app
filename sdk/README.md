# BrowserPDF browser SDK

This source-available, browser-only ESM package exposes versioned local PDF operations. It does not upload files, trigger downloads, register WebMCP tools, load analytics, or depend on the BrowserPDF site shell.

Package release `0.1.0` exports the stable API generation as `API_VERSION === 'v1'`; `PACKAGE_VERSION` tracks the package manifest independently.

## Runtime contract

Install exactly `pdf-lib@1.17.1` and `pdfjs-dist@6.1.200` alongside this package. These are exact peer dependencies, not bundled files. Configure PDF.js with the worker from the same installed `pdfjs-dist@6.1.200` package and serve its `standard_fonts`, `cmaps`, and `wasm` directories locally when the input needs them. Do not mix API and worker versions.

```js
import * as pdfLib from 'pdf-lib';
import * as pdfjs from 'pdfjs-dist';
import { mergeV1, inspectV1, diagnoseV1, normalizeV1 } from '@browserpdf/sdk/v1';

// Copy these files from the exact installed peer into your own static assets.
pdfjs.GlobalWorkerOptions.workerSrc = '/vendor/pdfjs-6.1.200/pdf.worker.min.mjs';
const pdfjsAssets = {
  standardFontDataUrl: '/vendor/pdfjs-6.1.200/standard_fonts/',
  cMapUrl: '/vendor/pdfjs-6.1.200/cmaps/', cMapPacked: true,
  wasmUrl: '/vendor/pdfjs-6.1.200/wasm/',
};

const merged = await mergeV1([firstBlob, secondBlob], { pdfLib, signal });
const privacy = await inspectV1(firstBlob, { pdfjs, pdfjsAssets, signal });
const quick = await diagnoseV1(firstBlob, { pdfLib, pdfjs, pdfjsAssets, mode: 'quick', signal });
const normalized = await normalizeV1(firstBlob, { pdfLib, pdfjs, pdfjsAssets, createCanvas, signal });
```

Deep diagnosis and normalization render pages. Supply `createCanvas(width, height)` explicitly; the SDK never queries the DOM. Inputs are copied before processing. Progress callbacks receive structured objects. Generated bytes are returned to the caller and never downloaded automatically.

`inspectV1` can include bounded raw sensitive-text matches in its direct return value. Treat the report as private document data. The diagnostic and privacy reports are bounded signals, not comprehensive security, repair, accessibility, PDF/A, or PDF/UA assessments. Normalization reserializes into a new, unencrypted file and can invalidate signatures or omit unsupported structures.

## Build and test

`npm run build` deletes only `sdk/dist`, then copies an explicit allowlist of DOM-free shared cores. `npm run check:dist` rejects missing, stale, or unexpected output. `npm test` builds, verifies declarations, and runs unit contracts. The browser consumer in `example/` is exercised in Chromium by the repository tests.

Only Chromium is currently tested. No package has been published by this repository task.
